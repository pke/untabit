Privacy Policy

Untabit browser extension · Last updated: August 12, 2026

No data. Really.

Untabit does not collect, store, transmit, or share any user data. There are no analytics, no tracking, and no external network requests of any kind — the extension contains no code that communicates with any server.

What the extension remembers

The only thing Untabit keeps is which window a popped-out tab came from, so the tab can be merged back. This is held in the browser's session storage on your device, never written to disk, never leaves your machine, and is deleted automatically when you close the browser.

Permissions

Untabit requires no access to your browsing history, page contents, or any website data. Its single permission (storage) exists solely for the session bookkeeping described above.
