Support

Answers first, contact below.

How do I use Untabit?

Press Alt + U (macOS: Ctrl + U) or click the toolbar icon. A tab with siblings pops out into its own window; a tab alone in its window merges back where it came from, at its old position.

The shortcut doesn't work

Most likely another extension registered it first. Untabit shows a red ! badge on its toolbar icon when that happens — click the badged icon and it takes you to the fix. You can rebind the shortcut anytime: chrome://extensions/shortcuts in Chrome/Brave/Edge, or in Firefox under about:addons → gear icon → Manage Extension Shortcuts.

I don't see the toolbar icon

It may be tucked behind the puzzle-piece extensions menu. Open that menu and pin Untabit to the toolbar.

Where does the tab go when I merge it back?

Back to the window it came from, at its old position. If that window was closed in the meantime, it joins the window you used most recently instead. Incognito/private tabs only ever merge into matching windows.

Does the page reload when a tab moves?

No. The tab is moved, not reopened — video keeps playing, scroll position and form state survive.

Report a bug or request a feature

Open an issue on GitHub — please include your browser and version. For anything else: untabit.extension@dudesoft.app
